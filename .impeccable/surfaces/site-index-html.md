# Surface: beta front page (site/index.html)

Mode: Read. Visitors are students opening the beta link; they need to know it's a beta, that it may be slow, that a sign-in comes if it goes public, see what changed, find the code, and get to the map in one tap.

Direction: intentionally amateur and bare-bones (user request): one narrow column, plain HTML feel, Comic Sans headings, default-blue links, dashed yellow warning box, BETA sticker, one green Continue button to map.html. Version history mirrors what was actually built (v0.1–v0.8).

Constraints: old deep links (#room=, #from=&to=) on the front page redirect to map.html. The GitHub repo is private, so the GitHub link only works for people with access until it is made public.
